# ÁgapePlay Rádio Indoor 🎵📢

Plataforma profissional de rádio indoor para lojas e redes.

---

## ✅ Recursos

- Reprodução automática de músicas
- Avisos programados por intervalo
- Painel Admin e Manager
- Controle de playlists por loja
- Supabase (Auth, Database, Storage)
- Deploy na Vercel

---

## 🚀 Tecnologias

- React + Vite
- TypeScript
- Supabase
- TailwindCSS
- Vercel Hosting

---

## 🌐 Projeto

O **ÁgapePlay** é um sistema completo para sonorização indoor, ideal para lojas, supermercados e redes comerciais.
